# Strength Tracker – update met Full Body

Deze update voegt een derde trainingskeuze toe: **Full Body**. De bestaande Upper Body- en Lower Body-workouts blijven beschikbaar.

## Bestanden uploaden naar GitHub
1. Pak `strength_tracker_iphone_app.zip` uit op je Mac.
2. Open je GitHub-repository `strength-tracker`.
3. Open de map/hoofdpagina van de repository.
4. Klik op **Add file → Upload files**.
5. Sleep de vijf bestanden uit deze map naar GitHub.
6. Als GitHub vraagt of bestanden met dezelfde naam vervangen moeten worden, bevestig dit.
7. Klik onderaan op **Commit changes**.

Upload de bestanden in de hoofdmap van de repository, dus niet in een extra map.

## Wat is aangepast?
- Een knop **Full Body** op het startscherm.
- Full Body staat ook bij het overzicht van je trainingsschema.
- De Full Body-oefeningen zijn toegevoegd aan de oefenkeuzelijst:
  Squat, Bench press, Lat pulldown, Romanian deadlift, Shoulder press, Bicep curl en Tricep pushdown.

## Daarna
GitHub Pages publiceert de wijziging meestal binnen enkele minuten. Open daarna je bestaande app-adres opnieuw in Safari. Als je nog de oude versie ziet, sluit de app volledig en open hem opnieuw. Eventueel kun je de pagina in Safari verversen.

## Gegevens
De app bewaart trainingsgegevens lokaal op het toestel in de browser. De update verandert de opslag niet. Maak regelmatig een back-up via Records → Exporteer back-up.
